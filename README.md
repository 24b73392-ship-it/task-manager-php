
# Task Manager — тапсырмаларды басқару жүйесі

## Жоба сипаттамасы
Task Manager — PHP және MySQL технологиялары арқылы әзірленетін веб-қосымша.

## Жобаның мақсаты
Пайдаланушыларға күнделікті тапсырмаларын жоспарлауға, сақтауға және басқаруға мүмкіндік беру.

## Негізгі функциялар
- Пайдаланушыны тіркеу
- Жүйеге кіру және шығу
- Жаңа тапсырма қосу
- Тапсырманы қарау
- Тапсырманы өңдеу
- Тапсырманы жою
- Тапсырмаларды іздеу және сүзу
- Тапсырмаларды санаттарға бөлу

## Қолданылатын технологиялар
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- GitHub

## Сайттың беттері
1. Басты бет
2. Тіркелу беті
3. Кіру беті
4. Тапсырмалар беті
5. Тапсырманы қосу/өңдеу беті

## Дерекқор кестелері
- users
- categories
- tasks

## 8-апта
Жоба тақырыбы таңдалды, мақсаты мен функциялары анықталды, беттердің тізімі және ER-диаграмма дайындалды.
