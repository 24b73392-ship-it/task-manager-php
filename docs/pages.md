
# Task Manager — Сайт беттерінің жоспары

## 1. Басты бет (index.php)
Жоба туралы жалпы ақпарат көрсетіледі.

## 2. Тіркелу беті (register.php)
Жаңа пайдаланушы тіркеле алады.

## 3. Кіру беті (login.php)
Пайдаланушы email және құпиясөз арқылы кіреді.

## 4. Тапсырмалар беті (tasks.php)
Барлық тапсырмалар көрсетіледі.

## 5. Тапсырма қосу (create.php)
Жаңа тапсырма қосуға болады.

## 6. Тапсырманы өңдеу (edit.php)
Тапсырманың атауын, мерзімін және статусын өзгертуге болады.

## 7. Шығу (logout.php)
Пайдаланушы жүйеден шығады.

## Қолданылатын технологиялар
- HTML
- CSS
- JavaScript
- PHP
- MySQL
